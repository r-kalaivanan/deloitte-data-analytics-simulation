# Deloitte Data Analytics Job Simulation

## Overview

This project is based on a job simulation by Deloitte, where real-world data analytics tasks were performed to solve business problems.

## Task 1: Telemetry Data Analysis

* Built an interactive Tableau dashboard to analyze machine telemetry data
* Identified factories with the highest downtime
* Performed root cause analysis to determine machine types contributing to failures

### Key Insight:

The Seiko factory showed the highest downtime, primarily driven by specific machine failures.

## Task 2: Forensic Analysis (Gender Pay Equality)

* Analyzed employee compensation data
* Classified equality scores into:

  * Fair
  * Unfair
  * Highly Discriminative
* Identified potential inequality patterns across job roles

## Skills Demonstrated
